# 🌺 Orquídea Morada

Tema para VS Code inspirado en las orquídeas moradas de Venezuela 🇻🇪. Diseño moderno con alto contraste y acentos violetas.

## Versiones

- **🌙 Dark**: Fondo profundo con acentos morados vibrantes
- **☀️ Light**: Fondo claro con toques morados elegantes

## Instalación

1. Abre VS Code
2. Ve a Extensiones (`Ctrl+Shift+X`)
3. Busca "Orquídea Morada"
4. Instala y selecciona el tema en `Archivo > Preferencias > Tema de Color`

## Paleta de Colores

**Dark**: `#2D1B3D` · `#E9E7F1` · `#B366FF`
**Light**: `#FDFCFF` · `#2D1B3D` · `#8E5BFF`
